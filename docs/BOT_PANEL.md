# Панель в Telegram-чате

Сайт и домен не требуются. Панель — сообщение с обычными кнопками и командами
бота, а не Telegram Mini App. Компьютер с MCP и Chrome должен оставаться включён.
Токен берётся из уже защищённой локальной настройки уведомлений.

- «Быстрый поиск» предлагает ввести запрос и показывает до пяти карточек.
- `/search iPhone 15 Pro Max` сразу выполняет поиск без отдельного шага ввода.
- «Последние 5 объявлений» / `/latest` показывает сохранённый последний поиск,
  с временем сбора. Если быстрого поиска ещё не было — последние пять событий
  мониторинга. Запрос к Avito в этом случае не выполняется.
- «Мои поиски» / `/watches` показывает сохранённые поиски и их состояние.
- `/menu` возвращает кнопки панели.

Быстрый поиск берёт город последнего сохранённого поиска, сортирует выдачу
Avito по дате и возвращает первые пять карточек с подтверждённым городом.
Другие фильтры мониторинга в быстром поиске не применяются. Продвигаемые
карточки и неполная дата Avito могут влиять на порядок выдачи; показывается
дата как на сайте, без утверждения, что это исходная дата публикации.
Не чаще одного поиска за 30 секунд. Глобальная пауза после HTTP 429 сохраняется.

Входящие команды обрабатываются через getUpdates (long polling), без webhook
или публичного порта. offset и обработанные update_id сохраняются локально;
повтор одного update после перезапуска не вызывает повторного ответа.
Сообщения, существовавшие до первого включения панели, не выполняются.
Ответы с неясным результатом отправки автоматически не повторяются.

Отвечает только привязанному владельцу в его личном чате: проверяются и ID
чата, и ID отправителя. Команды устанавливаются только для этого чата. Иные
пользователи и группы не получают результаты. Тексты входящих сообщений,
ID получателя и токен не попадают в журналы или исходный код.

Локальная команда открытия панели: POST /api/telegram/panel с обычной защитой
Origin и ключом локальной страницы. Чтение API панели не позволяет менять
получателя, открывать общий доступ или публиковать настройки.
